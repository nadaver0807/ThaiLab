# תיקיית תמונות האתר

הכניסו לכאן את קבצי התמונות **בדיוק בשמות הבאים**, והם יוצגו אוטומטית באתר במקומות המתאימים.
(הנתיב באתר הוא `/images/<שם-הקובץ>`.)

## תמונות נדרשות

| שם הקובץ         | היכן זה מופיע                    | המלצת גודל / יחס        |
| ---------------- | -------------------------------- | ----------------------- |
| `hero-curry.jpg` | סליידר ה-Hero (שקופית 1) + גלריה | 1920×1080, לרוחב (16:9) |
| `hero-chef.jpg`  | סליידר ה-Hero (שקופית 2) + גלריה | 1920×1080, לרוחב (16:9) |
| `hero-table.jpg` | סליידר ה-Hero (שקופית 3) + גלריה | 1920×1080, לרוחב (16:9) |

> **הערה:** שלוש התמונות האלה משמשות גם ב-Hero וגם בגלריה, אז מספיק להעלות את שלושתן.

## טיפים

- מומלץ פורמט `.jpg` לצילומים (קובץ קל יותר) או `.webp` לאיכות/משקל מיטביים.
- אם תרצו להשתמש ב-`.webp` או `.png` במקום `.jpg`, צריך לעדכן את שמות הקבצים בקוד:
  - `client/src/components/home/hero-carousel/HeroCarousel.const.ts`
  - `client/src/components/home/gallery-section/GallerySection.const.ts`
- שמרו על שמות קבצים באנגלית, ללא רווחים.
- לאחר הוספת הקבצים, רעננו את הדפדפן (או הריצו מחדש את שרת הפיתוח) כדי לראות את התמונות.
